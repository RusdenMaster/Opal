Opal سفن GraalVM محرك JavaScript، بيئة تشغيل JS كاملة تعمل داخل Minecraft العميل. أنت تكتب نصوصًا تتحدث إلى Opal'تتيح واجهات برمجة التطبيقات الداخلية الخاصة به الوصول إلى بيانات اللعبة أثناء تشغيلها. هذا ليس مسجل ماكرو أو نظام ربط مفاتيح. بل هو بيئة برمجة حقيقية مع إمكانية الوصول إلى نظام أحداث العميل، وتكوينات الوحدات، وحالة اللعبة.

<KeyTakeaways>

- بيئة تشغيل JavaScript كاملة من GraalVM، وليست مسجل ماكرو.
- استجب لأحداث اللعبة، وقم بتغيير إعدادات الوحدة، وارسم واجهة المستخدم الخاصة بك.
- يتم تحميل النصوص البرمجية في وقت التشغيل، بدون إعادة تشغيل، وتعمل في بيئة معزولة لحماية واجهات برمجة التطبيقات الخاصة بـ Opal.
- تتوقف معظم العملاء الآخرين عند الماكرو الأساسية.

</KeyTakeaways>

## لماذا GraalVM؟
GraalVM هو بيئة تشغيل متعددة اللغات من Oracle. اخترناه لأسباب ملموسة:

- السرعة: يضمن التحويل البرمجي في الوقت المناسب بقاء النصوص البرمجية سريعة بما يكفي للتشغيل في كل دورة.
- JavaScript: معظم الناس يعرفونها بالفعل، لذا فإن منحنى التعلم قصير.
- أمان سلاسل العمليات: تتعامل الروابط بين JavaScript و Java مع التزامن بشكل صحيح بدلاً من تركك تتعثر فيه.
- أنماط مألوفة: تتصرف واجهات برمجة التطبيقات القياسية لـ JavaScript بالطريقة التي تتوقعها
## ما يمكنك أن تبني

### الأتمتة المخصصة
استجب للأحداث داخل اللعبة:

```javascript
// Auto-respond to certain chat messages
on('chat', (event) => {
  if (event.message.includes('1v1?')) {
    sendChat('/duel accept');
  }
});
```
### تكوين وحدة ديناميكي
تغيير إعدادات الوحدة النمطية بناءً على حالة اللعبة:

```javascript
// Increase reach when health is low
on('tick', () => {
  const health = player.getHealth();
  if (health < 8) {
    modules.get('Reach').setSetting('distance', 3.3);
  } else {
    modules.get('Reach').setSetting('distance', 3.1);
  }
});
```
### عناصر واجهة المستخدم المخصصة
ارسم طبقاتك الخاصة:

```javascript
// Display a combo counter on screen
let combo = 0;
on('attackEntity', () => { combo++; });
on('damage', () => { combo = 0; });
on('render2d', (ctx) => {
  ctx.drawText(`Combo: ${combo}`, 10, 10, 0xFFFFFF);
});
```
### ملفات تعريف خاصة بالخادم
تبديل إعدادات التكوين تلقائيًا عند الانضمام إلى خوادم مختلفة:

```javascript
on('serverJoin', (event) => {
  if (event.ip.includes('pvp.example.com')) {
    loadConfig('server-bypass');
  } else {
    loadConfig('ghost-default');
  }
});
```
