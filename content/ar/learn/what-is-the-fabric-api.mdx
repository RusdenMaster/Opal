<KeyTakeaways>

- واجهة برمجة التطبيقات Fabric هي مكتبة مشتركة من الخطافات والمساعدات التي تُصنع معظم تعديلات Fabric عليها.
- وهي منفصلة عن المُحمِّل عن قصد: مُحمِّل صغير يتحدث بسرعة، بينما تتطور واجهة برمجة التطبيقات بشكل مستقل.
- إنها توفر أحداثًا، وشبكات، وتسجيلات، ومساعدات عرض تعتمد عليها العديد من التعديلات.
- غالبًا ما يكون عدم وجود واجهة برمجة التطبيقات Fabric أو كونها قديمة هي السبب في تعطل التعديل عند التشغيل.

</KeyTakeaways>

تُعد واجهة برمجة التطبيقات Fabric مكتبة مشتركة من الخطافات والمساعدات التي تُصنع معظم تعديلات [Fabric](https://fabricmc.net/) وفقًا لها. يتميز مُحمِّل Fabric الأساسي بحجمه الصغير عن قصد، لذا فإن واجهة برمجة التطبيقات تملأ الفراغات: الأحداث، والشبكات، ومساعدات التسجيل، وأدوات العرض. إذا تعطل تعديل Fabric عند التشغيل بسبب خطأ في الفئة المفقودة، فإن واجهة برمجة التطبيقات Fabric الغائبة أو قديمة الإصدار هي السبب المعتاد.

## لماذا فصله عن المحمل

تقسم Fabric النظام إلى قسمين عن قصد. يبقى المحمل صغيرًا ومستقرًا، بينما يتم شحن Fabric API بمجموعة الواجهات المشتركة الأكبر والأسرع. يسمح هذا التقسيم للمحمل بالتحديث إلى إصدار جديد من Minecraft بسرعة بينما يتطور الـ API بوتيرة خاصة به.

## ما الذي يوفره

يوفر الـ API للمعدّلات طريقة مشتركة ومستقرة الإصدار للقيام بالأشياء التي تحتاجها العديد من المعدّلات:

- أحداث دورة الحياة والألعاب المراد الربط بها.
- أدوات مساعدة للشبكات للحزم المخصصة.
- أدوات مساعدة للتسجيل والمحتوى لإضافة العناصر والكتل والكيانات.
- أدوات مساعدة للعرض والموارد مشتركة بين المعدّلات.

بدونه، سيعيد كل معدّل اختراع هذه الأجزاء ويؤدي إلى تعطيل بعضها البعض.

## هل أنت بحاجة إليه؟

في الغالب، نعم. معظم تعديلات Fabric تسرد Fabric API كاعتمادية، لذا تقوم بتثبيته مرة واحدة كتعديل إلى جانب التعديلات الأخرى. طابق نسخته مع إصدار Minecraft الخاص بك.
