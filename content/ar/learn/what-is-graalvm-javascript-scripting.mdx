<KeyTakeaways>

- GraalVM JavaScript هو محرك JavaScript سريع ومتوافق مع المعايير يعمل على JVM.
- تتضمن تطبيقات Java فيه حتى يتمكن المستخدمون من كتابة JavaScript التي تستدعي البرنامج المضيف.
- يتم إعادة تحميل النصوص البرمجية بشكل فوري، بحيث يمكنك تغيير السلوك دون إعادة تجميع كود Java.
- يحدد المضيف بدقة أي الكائنات والصفوف التي يمكن للنص البرمجي الوصول إليها.

</KeyTakeaways>

GraalVM JavaScript هو محرك JavaScript سريع ومتوافق مع المعايير، يعمل على JVM، وهو جزء من مشروع [GraalVM](https://www.graalvm.org/). تتضمن تطبيقات Java هذا المحرك لكي يتمكن المستخدمون من كتابة JavaScript التي تستدعي البرنامج المضيف وتُحمَّل في الوقت الفعلي. وفي تطبيق Java، يعني ذلك إضافة أو تغيير السلوك في JavaScript دون إعادة تجميع كود Java.

## GraalVM و GraalVM JavaScript

GraalVM هو بيئة تشغيل عالية الأداء يمكنها تشغيل لغات متعددة على JVM. محرك JavaScript الخاص به حديث بما يكفي لدعم أحدث ميزات ECMAScript. تقوم التطبيقات بشحن المحرك، وتقديم مجموعة من الكائنات للبرامج النصية للعمل بها، وتشغيلها.

## لماذا تقوم التطبيقات بتضمينه

- **إعادة التحميل السريع**: قم بتغيير برنامج نصي ولاحظ التأثير دون إعادة التشغيل أو إعادة البناء.
- **واجهة آمنة**: يحدد المضيف بالضبط الكائنات وفئات Java التي يمكن للبرنامج النصي الوصول إليها.
- **التكامل مع Java**: يمكن للبرامج النصية استدعاء التعليمات البرمجية الخاصة بالتطبيق من خلال الكائنات التي يعرضها.

## كيف يظهر في العميل

عادةً ما يوفر البرنامج الذي يضمّن المحرك نقاط دخول للبرامج النصية لتسجيل نفسها، ثم مجموعة صغيرة من كائنات "الوكيل" التي تربط JavaScript بالداخلية الخاصة بالبرنامج. يكتب المستخدم برنامجًا نصيًا، ويضعه في مجلد البرامج النصية، ويقوم المحرك بتحميله. بهذه الطريقة، يمكن للعميل السماح للمستخدمين بإضافة ميزات بلغة JavaScript بدلاً من تجميع تعديل.
