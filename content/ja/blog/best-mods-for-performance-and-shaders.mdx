高いフレームレートと高品質なシェーダーを同時に手に入れたいですか？[Fabric](https://fabricmc.net) なら、必要な要素はシンプルです。SodiumでFPSを最適化し、Irisでシェーダーを適用し、Lithiumでゲームロジックを処理します。すべて無料で、互いに連携するように設計されています。Opalユーザーへの注意点として、LithiumはOpalと互換性がないため、SodiumとIrisを中心に構築してください.

<KeyTakeaways>

- Sodiumはフレームレートを、Irisはシェーダーを提供し、それらは一緒に動作するように設計されています。
- Lithiumはゲームロジックの助けになりますが、Opalとは互換性がありません。
- SodiumやIrisの導入にはFabricローダー、FabricAPI、の導入が必要です。
- Opal単体ではグラフィックなどの性能が足りない場合も、Sodiumがそれを実行するための余裕を与えます。

</KeyTakeaways>

## Sodium：フレームレート

[Sodium](https://modrinth.com/mod/sodium) は、Minecraftのレンダリングを高速かつスムーズに書き換えます。その差は、特に性能の低いGPUで顕著になります。現代のパフォーマンス設定の基盤となるものであり、Opalと並行して問題なく動作します。インストール後、Irisを導入するとシェーダーが利用可能になります。

## Iris：シェーダー

[Iris](https://modrinth.com/mod/iris) は、Fabric上でシェーダーパックを実行するように設計されており、Sodium と連携することで、Sodiumによって得られたフレームレートを消費することなくシェーダーを実行できます。従来の方法でシェーダーを実行していた場合、これが最新のエコシステムとの連携がスムーズな方法です。

## Lithium：ゲームロジック関連 (Opal とは互換性なし)

[Lithium](https://modrinth.com/mod/lithium) は、ゲームロジック、MobのAI、物理演算、ティック処理を高速化します。見た目の変化はありません。バニラの設定に加えることで効果を発揮します。ただし、Opalとは互換性がないため、Opalを使用している場合は、インストールせずにSodiumを導入してください。

## 結論

| MOD | 役割 | Opal との互換性 |
| :--- | :--- | :--- |
| Sodium | レンダリングの軽量化 | はい |
| Iris | シェーダー | はい |
| Fabric API | 必須の基盤 | はい |
| Lithium | ゲームロジックのパフォーマンス向上 | いいえ |

<Callout variant="info" title="インストール順序">
Fabricローダーを最初に、次にFabricAPIをインストールし、その後、残りのものをインストールしてください。 ほとんどのFabric用ModはAPIがないとロードされません。そのため、Sodium、Iris、またはOpalの前にインストールする必要があります。
</Callout>

## Opalの配置場所

OpalはMinecraft 26.2用のFabricModです。そのため、SodiumやIrisと同じ`mods`フォルダに配置します。シェーダー対応ゲームに加え、戦闘、移動、視覚、ユーティリティのモジュール、UIにはLiquid Glassを採用し、さらにはスクリプトエンジンといった多くの機能が利用できます。Opalは大規模なModなので、Sodiumを導入しておくと動作に余裕を持たせることができます。
